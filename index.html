01 / IFIXIT

How repairable is a device?

The iFixit score ranges from 0 to 10. A higher score indicates better repairability. Depending on the rubric version, the assessment considers factors such as disassembly, documentation and spare parts.

Devices may have been assessed using different rubric versions. Identical scores do not necessarily reflect the same assessment criteria.

02 / FRENCH REPAIRABILITY INDEX

A separate assessment method.

The French repairability index also uses a scale up to 10, but follows a different calculation. The two assessments are not combined into a single score.

Only unambiguous model matches with agreeing source scores are shown. Unclear variants and conflicting sources remain clearly identified.

BACKGROUND & CREDITS

About this project.

The officially unofficial listing of iFixit's repairability scores.

Where it started

Inspired by xiongchiamiov’s repairability-scores project and the original webpage. Rewritten with the latest data.

What you can explore

Search and compare devices, explore the score distribution, inspect scoring rubrics, and follow links to teardowns and original sources. French repairability-index values are shown separately because they use a different method.

Data sources

Device information and iFixit repairability scores come from iFixit. French index values come from indicereparabilite.fr. Open a device to inspect its model information and source evidence.

Device images are supplied by iFixit. See each linked device page for image credits and iFixit’s content licence.

The dataset is refreshed daily from iFixit and the French source catalogue. Source conflicts remain visible; the last validated data is retained if an import fails.
